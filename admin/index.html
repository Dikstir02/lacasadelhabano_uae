One-time token setup

  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access → Only select repositories → Dikstir02/lacasadelhabano_uae.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Choose an expiry, generate it, then paste the token above and press Save connection.

If you clear this browser's storage, or the token expires, publishing stops silently — come back here and paste a fresh one. The manual Copy … buttons still work as a fallback.
